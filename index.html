PROJECT · TIPE 2025–2026

Designing a nuclear-waste drum pusher robot

In a two-person project at Lycée Carnot, I designed and prototyped a robot inspired by an industrial system for moving waste drums in underground storage galleries. The prototype explored a pneumatic anchoring and movement mechanism, controlled and tested through iterative improvements. It allowed me to learn how to control components using Arduino and to apply an experimental approach to improving a mechatronic system. Yet the most interesting and difficult part was modelling the pneumatic system in order to implement a closed-loop pressure control system for the pump.
